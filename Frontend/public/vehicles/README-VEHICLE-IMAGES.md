# Vehicle Images Guide

## Image Naming Convention

Images should be named following this pattern:
```
{make}-{model}.jpg
```

**Examples:**
- `toyota-camry.jpg`
- `honda-civic.jpg`
- `mercedes-benz-s-class.jpg`
- `bmw-7-series.jpg`
- `ford-f-150.jpg`

## Rules:
1. **Lowercase only** - All letters must be lowercase
2. **Hyphens for spaces** - Replace spaces with hyphens (-)
3. **Remove special characters** - No special characters except hyphens
4. **JPG format** - Use .jpg extension

## Image Specifications:

### Recommended:
- **Format**: JPG
- **Dimensions**: 800x600px or 1200x800px
- **Aspect Ratio**: 4:3 or 16:9
- **File Size**: Under 200KB (optimized for web)
- **Quality**: High quality, clear vehicle shots

### Best Practices:
- Professional automotive photography
- Clean background (preferably white or showroom)
- Side or 3/4 angle view
- Good lighting
- No watermarks or text overlays

## Placeholder Image:

If an image is not found, the system automatically falls back to:
```
/vehicles/placeholder.jpg
```

Replace this with a generic car placeholder image.
