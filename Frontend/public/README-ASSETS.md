# Hero Assets

## Required Files

Place your hero background media in this directory:

1. **hero-video.mp4** - Background video for the landing page
   - Recommended: 1920x1080 or higher resolution
   - Format: MP4 (H.264 codec)
   - Duration: 10-30 seconds (will loop)
   - Content: Professional car/dealership footage
   - File size: Keep under 10MB for fast loading

2. **hero-image.jpg** - Fallback image if video doesn't load
   - Resolution: 1920x1080 minimum
   - Format: JPG or PNG
   - Content: Should match the video theme
   - File size: Optimized, under 500KB

## Tips

- Use high-quality, professional automotive footage
- Ensure the video is dark enough that white text is readable
- Compress the video for web (you can use HandBrake or similar tools)
- Test on different devices and connection speeds

## Example Sources

- Pexels.com (free stock videos)
- Pixabay.com (free stock videos)
- Your own dealership footage

Just replace the placeholder files with your actual video and image!
